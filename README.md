# Teste Estágio Target

Este repositório contém um exercício prático desenvolvido como parte do processo seletivo para estágio na empresa Target.

## Estrutura do Projeto
```bash
TESTE_ESTAGIO_TARGET/
├── Exercicio3/            # Diretório do exercício 3
│   ├── script.py          # Script Python do exercício
├── README.md              # Este arquivo
```
## Descrição do Exercício

O exercício consiste em desenvolver um script Python que resolve um problema específico. O código está localizado no diretório Exercicio3/ e foi implementado no arquivo script.py.

## Como Executar
git clone https://github.com/crissmcoelho/TESTE_ESTAGIO_TARGET.git
cd TESTE_ESTAGIO_TARGET

## Navegue até o diretório do exercício:
cd Exercicio3

## Execute o script:
python script.py
